# Controls: The Pump House

| Action | Keyboard + mouse | Gamepad |
|---|---|---|
| Move / look | WASD + mouse | Sticks |
| Jump | Space | A |
| Pick up / put down (cells, crates, Pebble) | E | X |
| Throw | Left mouse | RT |
| Tether: plug into a socket / pull a crate | Right mouse | LT |
| **Hint** (each press tells you more) | **H** | **D-pad down** |
| **Reset this room** | stand on the red pad 1 s | same |
| Pause / restart the whole call | Esc / Backspace | Start / Select |

Reading the machines: a cell's **bars** show its charge (all four green = full). A cradle's **lamp**: dark empty,
amber not full, blue pulsing charging, green powering. The **needle** shows weight in the pan; the green tick is full.
Coral things (gate, pans, bridge, their floor wires) belong to one pulley; blue wires carry cell power.
